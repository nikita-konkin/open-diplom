# Прототип на Java 11

Проверка решения [ADR-0007](architecture/adr/0007-technology-stack.md) и перенос правил из текущего сервиса ([diploma_supplement_service](https://github.com/nikita-konkin/diploma_supplement_service)). Состояние на 26.09.2026.

## Что умеет прототип

- Веб-страница на встроенном Tomcat 10.1. В настольном режиме программа слушает только 127.0.0.1 и сама открывает браузер.
- Импорт ведомости «Деканата» (`.xls` или `.xlsx`) и, по желанию, учебного плана. Семестры складываются, з.е. берутся из плана, для оператора — таблица пометок. Результат сохраняется в промежуточной зоне SQLite.
- Тестовый лист калибровки принтера (PDF, A4 альбомный) с поправками вправо и вниз в миллиметрах.
- XML «ФайлОбменаКиберДиплом» 3.5.1 из сводной таблицы и сведений о студентах: переходный период, пока печатает КиберДиплом.

## Результаты по критериям ADR-0007

Замеры сделаны в Linux-контейнерах OrbStack на Mac (arm64 и x86-64 через Rosetta). На каждом прогоне 9 запросов: трижды импорт реальной ведомости (141 КБ) с учебным планом, тестовый лист и XML по реальной сводной.

| Критерий | Требование | Результат |
|---|---|---|
| Запуск без установки | рантайм в поставке | урезанный jlink-рантайм 51 МБ (arm64) / 56 МБ (x86-64) и программа 39 МБ |
| Время запуска | меньше 5 с | 0,3 с (arm64), 0,7 с (x86-64 через Rosetta) |
| Память | меньше 300 МБ | пик 243 МБ (arm64) и 276 МБ (x86-64) с настройками запускателя: куча 128 МБ, последовательный сборщик мусора, только компилятор C1. С настройками JVM по умолчанию — 402 МБ, поэтому запускатель их задаёт |
| `.xls` и `.xlsx` | оба формата | формат определяется по сигнатуре файла; проверено тестами и 93 книгами архива |
| SQLite | запись и чтение | промежуточная зона импорта, миграции схемы; данные переживают перезапуск (тест) |
| PDF в миллиметрах | отклонение поля не больше 0,5 мм | в PDF поле стоит на заданном месте с точностью 0,5 мм, поправка калибровки сдвигает его (тесты читают координаты обратно из PDF). **Отпечаток на бумаге не проверен** — нужен принтер |
| Кириллический шрифт | PT Astra Serif | шрифт ищется в системе: PT Astra Serif (Astra), Times New Roman (Windows), Liberation Serif (РЕД ОС, Альт) — у всех метрики Times New Roman — и встраивается в PDF. Проверено с Times New Roman |
| Браузеры | Chrome 109, Firefox ESR 115 | страницы — обычный HTML без скриптов; в старых браузерах не открывались |
| Windows 7 x86, Astra с ЗПС | запуск | **не проверено**: стенды отложены (T-01…T-07 в [backlog текущего сервиса](https://github.com/nikita-konkin/diploma_supplement_service/blob/main/docs/BACKLOG.md)) |

Вывод: всё, что можно проверить без стендов, в критерии укладывается. Главный оставшийся риск — Windows 7 x86 с 2 ГБ памяти (T-01). 32-битная JVM расходует меньше памяти, чем 64-битная, так что запас есть, но это надо подтвердить на стенде.

## Перенесённые правила

| Что | Откуда | Куда |
|---|---|---|
| Чтение ведомости «Деканата»: макет, строки «Всего», «V» → 6 | `parser.py` | `imports.StatementReader` |
| Сложение семестров (B-31): часы всех строк, приоритет экзамена, курсовая отдельно | `parser.py` | `imports.SemesterRecords` |
| З.е. из учебного плана, оба формата плана | `curriculum.py` | `imports.Curriculum` |
| Пометки для оператора о з.е. | `parser.settle_credits` | `imports.CreditCheck` |
| Проверки сведений, сопоставление студентов, XML 3.5.1 | `xml_generator.py` | `export.PivotSource`, `export.CyberDiplomaXml` |

Намеренно **не перенесено** сопоставление строк ведомости со «Списком дисциплин» (`parse_discipline`, `match_row`). Это эвристика по подстрокам, и из неё выросли ошибки текущего сервиса. В новой системе строки ведомости сопоставляются с учебным планом в промежуточной зоне, а оператор подтверждает результат ([ADR-0004](architecture/adr/0004-import-staging-area.md)). Факультативы будут определяться по блоку ФТД учебного плана, а не по списку дисциплин.

### Как проверен перенос

- **65 тестов** на JDK 11: 44 сценария перенесены из Python-тестов (13 — ведомость и з.е., 31 — XML), остальные новые — печать, хранилище, HTTP с кириллическими именами файлов.
- **Проверка поломками.** В копию кода по очереди вносились ошибки: убран приоритет экзамена, отключена поправка калибровки, государственный экзамен поставлен после ВКР, имена файлов читались в ISO-8859-1. Каждую поломку тесты поймали. Удаление явной настройки UTF-8 тесты не заметили, и это верно: Tomcat 10.1 и без неё читает имена в UTF-8.
- **Сверка с Python на реальных данных** (локально, данные никуда не передавались). Обе реализации прогнаны по всем 93 книгам архива 2019–2026:
  - 105 разборов ведомостей: 4 ведомости без плана и с каждым из 3 планов (172 листа студентов, 748 строк, 712 проверок з.е.), плюс сообщения об ошибке на книгах другого вида;
  - 93 чтения учебного плана;
  - 60 пар «сводная × сведения»: 4 готовых XML общим объёмом 438 тыс. символов и 56 списков ошибок.

  Расхождений нет, XML совпали побайтно.

Повторить сверку (нужны виртуальные окружения текущего сервиса):

```sh
mvn -DskipTests package test-compile
java -cp target/open-diplom.jar:target/test-classes org.opendiplom.tools.RegressionDump statement list.txt > java.jsonl
python tools/regression/python_dump.py <путь к diploma_supplement_service> statement list.txt > python.jsonl
python tools/regression/compare.py python.jsonl java.jsonl
```

В `list.txt` — пути к файлам, по строке на прогон (для ведомости с планом — два пути через табуляцию). Выгрузки содержат персональные данные: храните их только на машине, где лежат файлы.

## Что дальше

1. Стенды T-01…T-07, в первую очередь Windows 7 SP1 32 бит с Liberica JDK 11 x86 и Astra Linux 1.7. Там же проверить Java 17 x86 (T-02): для Java 11 многие библиотеки уже не обновляются (ADR-0007).
2. Напечатать тестовый лист (`/test-sheet.pdf`) на принтере, где печатаются бланки, и измерить отклонение.
3. Уменьшить поставку: в jar лежат нативные библиотеки SQLite для всех платформ, а нужны только Windows и Linux.
4. Модель данных картотеки и сопоставление ведомости с учебным планом в промежуточной зоне — начало MVP.
