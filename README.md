# Открытый диплом

Открытая система подготовки и печати дипломов о высшем образовании и приложений к ним. Цель — заменить закрытую программу КиберДиплом, в том числе в вузах, где работают старые компьютеры (Windows 7, 32 бита) и российские Linux (Astra, РЕД ОС, Альт).

**Статус: прототип.** Архитектура и стек согласованы, общие правила импорта и выгрузки перенесены из [текущего сервиса](https://github.com/nikita-konkin/diploma_supplement_service) и сверены с ним на реальных данных. Картотеки и печати на бланках пока нет. Подробности — в [docs/prototype.md](docs/prototype.md).

## Что должно получиться

- **Картотека выпускников:** дипломы, приложения, решения ГЭК, книга регистрации, проверка по приказам Минобрнауки № 645 и № 670.
- **Импорт** ведомостей «Деканата» и учебных планов через промежуточную зону: ничего не попадает в картотеку без подтверждения оператора.
- **Печать на бланках** по шаблонам в миллиметрах с калибровкой принтера; первый шаблон — бланки «Полиграфзащиты».
- **Выгрузка** XML для КиберДиплома на переходный период; после MVP — ФИС ФРДО.
- **Два режима одной сборки:** один компьютер без сети (SQLite) и сервер вуза для нескольких пользователей (PostgreSQL).

Архитектура — [docs/architecture](docs/architecture/README.md), решения — [ADR](docs/architecture/adr).

## Сборка и запуск

Нужна JDK 11 или новее и Maven 3.9. Без них собирать можно в Docker:

```sh
docker run --rm -v "$PWD":/build -w /build maven:3.9-eclipse-temurin-11 mvn -B package
```

Запуск:

```sh
java -jar target/open-diplom.jar
```

Программа откроет браузер на http://127.0.0.1:8090/ и создаст папку `data` с базой SQLite.

Поставка без установленной Java: `scripts/build-dist.sh` собирает папку `dist/open-diplom` — урезанный рантайм, программу и запускатели `open-diplom.cmd` (Windows) и `open-diplom.sh`.

На сервере с Docker — контейнер (сборка образа прогоняет все тесты):

```sh
docker build -t open-diplom .
docker run -d -p 8090:8090 -v "$PWD/data":/data open-diplom
```

Папка `data` на хосте должна принадлежать uid 1000. Настройки — через `-e JAVA_OPTS="-Dopendiplom.context-path=/open-diplom"`.

## Настройки

Файл `open-diplom.properties` в рабочей папке или параметры `-Dopendiplom.<имя>=…`:

| Имя | По умолчанию | Что задаёт |
|---|---|---|
| `mode` | `desktop` | `desktop` — только этот компьютер; `server` — доступ по сети |
| `address` | `127.0.0.1` на одном компьютере, `0.0.0.0` на сервере | адрес, на котором программа принимает соединения |
| `port` | `8090` | порт веб-интерфейса |
| `context-path` | пусто | префикс адреса за обратным прокси: `/open-diplom` для `https://example.org/open-diplom/` |
| `data` | `data` | папка с базой и временными файлами |
| `database` | SQLite в папке `data` | JDBC-адрес базы |
| `font` | ищется в системе | файл шрифта TrueType с кириллицей для печати |
| `max-upload-mb` | `20` | наибольший загружаемый файл, МБ |
| `open-browser` | `true` | открывать ли браузер при запуске на одном компьютере |

## Устройство кода

| Пакет | Модуль архитектуры |
|---|---|
| `org.opendiplom.sheets` | чтение книг `.xls` и `.xlsx` |
| `org.opendiplom.imports` | импорт: ведомости, учебный план (Excel или PDF из «Планов»), з.е. |
| `org.opendiplom.plans` | учебный план: строки, шапка, итоги, структура, контрольные суммы, сравнение |
| `org.opendiplom.graduation` | выпуск: сопоставление студентов и предметов ведомости с учебным планом, результаты |
| `org.opendiplom.catalog` | картотека: выпускники, результаты, документы, данные вуза, проверка, «с отличием» |
| `org.opendiplom.export` | сведения о студентах, выгрузка XML КиберДиплома 3.5.1 из сводной или из картотеки |
| `org.opendiplom.printing` | печать: шаблоны FastReport (`.fr3`), данные бланка, раскладка, PDF, калибровка |
| `org.opendiplom.storage` | база данных и миграции, учебные планы, выпуски, документы, шаблоны бланков |
| `org.opendiplom.web` | веб-интерфейс |

Тесты не используют реальные данные: книги, PDF, планы и шаблоны бланков строятся в памяти (`Books`, `PlanPdfs`, `Plans`, `Templates`). Реальные ведомости и приложения содержат персональные данные и не попадают в репозиторий — `.gitignore` запрещает `*.xls`, `*.xlsx` и `*.pdf`.
